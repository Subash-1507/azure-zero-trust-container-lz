Result: refused by Kubernetes' built-in Pod Security Admission, before the Gatekeeper webhook is even called.

## Why both layers matter
validation.gatekeeper.sh failurePolicy=Ignore
Gatekeeper fails open: if its pods are down, the API server admits pods unchecked.
Pod Security Admission runs inside the API server itself, so the app namespace stays protected either way.
